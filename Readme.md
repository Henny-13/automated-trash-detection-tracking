# Automated Trash Detection and Tracking System

## Project Overview
A Raspberry Pi-based automated object detection and tracking system developed using Python and computer vision technologies. The project explores how a camera and computer vision algorithms can identify and track moving objects.

## Technologies Used
- Python
- Raspberry Pi
- OpenCV
- Flask
- Picamera2
- Embedded Systems

## Key Features
- Camera-based object detection.
- Motion detection using OpenCV MOG2 background subtraction.
- Target filtering and tracking logic.
- Flask-based web interface.
- Hardware and software integration.
- Motor control integration.

## Technical Implementation
The system uses a Raspberry Pi camera to capture video input. OpenCV processes the video frames using background subtraction techniques to identify moving objects. Python modules handle tracking logic and system control, while Flask provides a web interface for interacting with the application.
